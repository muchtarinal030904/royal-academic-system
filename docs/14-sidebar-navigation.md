# Objective

Membangun sistem navigasi sidebar
yang modern,
responsif,
dan mudah digunakan
untuk seluruh user sistem.

Sidebar menjadi pusat navigasi utama
yang membantu user mengakses fitur
dengan cepat dan terstruktur.

---

# User Roles

## Admin / Biro Akademik

Memiliki sidebar khusus admin.

---

## Mahasiswa

Memiliki sidebar khusus mahasiswa.

---

# Navigation Concept

Sistem menggunakan:

- fixed sidebar
- responsive drawer
- role-based navigation
- collapsible menu

---

# Main Features

## Fixed Sidebar

Sidebar tetap tampil pada desktop.

---

## Responsive Drawer

Sidebar berubah menjadi drawer pada mobile.

---

## Active Menu Highlight

Menu aktif memiliki indicator visual.

---

## Collapsible Sidebar

Sidebar dapat diperkecil.

---

## Role-Based Navigation

Menu tampil berdasarkan role user.
