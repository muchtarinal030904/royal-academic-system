# Objective

Membangun sistem manajemen mahasiswa
yang modern, cepat, aman,
dan mudah digunakan oleh Admin/Biro Akademik.

Fitur ini menjadi pusat utama
pengelolaan data mahasiswa
yang digunakan untuk pencetakan ijazah.

---

# User Role

## Admin / Biro Akademik

Hanya Admin/Biro Akademik
yang dapat mengakses fitur ini.

---

## Student List

## Student Import
