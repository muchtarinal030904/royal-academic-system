# STUDENT DASHBOARD UI POLISHING

Tujuan:
Kurangi kesan template admin dashboard dan ubah menjadi portal mahasiswa modern yang fokus pada status ijazah dan data akademik resmi.

---

## 1. HAPUS SEARCH BAR PALSU

Hapus search bar pada top navbar yang bertuliskan:

" Cari fitur atau data... "

Karena dashboard mahasiswa tidak membutuhkan fitur pencarian besar seperti admin panel.

Ganti area tersebut dengan informasi yang lebih relevan seperti:

- "Status Akademik: Aktif"
atau
- "Semester Genap 2026/2027"

Gunakan tampilan clean minimal modern.

---

## 2. PERBAIKI BRANDING SIDEBAR

Ganti teks branding sidebar:

"PRINT SUITE"

menjadi:

"PORTAL IJAZAH"

atau

"DOKUMEN AKADEMIK"

Tujuannya agar branding lebih relevan dengan sistem mahasiswa dan tidak terasa generic seperti software printing enterprise.

Pertahankan typography modern dan profesional.

---

## 3. PERBAIKI HERO DESCRIPTION

Ganti deskripsi pada welcome hero card menjadi:

"Pantau status penerbitan ijazah dan informasi akademik resmi Anda."

Kurangi teks yang terlalu panjang dan tutorial-like.

Pastikan hero terasa lebih clean, modern, dan fokus.

---

## 4. KURANGI VISUAL NOISE PADA HERO

Hapus badge kecil:

"PORTAL MAHASISWA"

karena informasi tersebut sudah jelas dari sidebar dan konteks halaman.

Biarkan hero lebih bersih dan fokus pada greeting user.

---

## 5. PERBAIKI SECTION PROSES IJAZAH

Ubah section "Proses Penerbitan Ijazah" menjadi timeline progress yang lebih hidup.

Contoh step:

✔ Verifikasi Data Akademik
✔ Validasi Fakultas
✔ Persetujuan Administrasi
⏳ Proses Penerbitan Ijazah

Tambahkan:
- progress line
- warna status
- indikator aktif
- tanggal update jika tersedia

Section ini harus menjadi fokus utama dashboard mahasiswa.

---

## 6. KURANGI WHITESPACE BERLEBIHAN

Kurangi:
- padding vertical card
- margin antar section
- tinggi hero card

Agar dashboard terasa lebih padat, profesional, dan tidak seperti template kosong.

Tetap pertahankan readability dan clean spacing.

---

## 7. SEDERHANAKAN CARD IPK

Kurangi elemen dekoratif berlebihan pada card IPK:
- kurangi border bertingkat
- kecilkan watermark icon
- sederhanakan nested card

Fokus utama:
- angka IPK
- predikat kelulusan

Gunakan style minimal modern academic dashboard.

---

## 8. KECILKAN SECTION UBAH PASSWORD

Section "Keamanan & Ubah Sandi" terlalu besar untuk fitur sekunder.

Ubah menjadi:
- card kecil
atau
- modal popup dari profile dropdown

Tujuannya agar dashboard lebih fokus pada data akademik dan status ijazah.

---

## 9. PERBAIKI TYPOGRAPHY HIERARCHY

Naikkan sedikit contrast teks label abu-abu seperti:
- Nama Lengkap
- Tahun Masuk
- Program Studi

Agar lebih readable dan premium.

Hindari teks abu terlalu pucat.

---

## 10. TARGET VISUAL AKHIR

Dashboard harus terasa seperti:

- Portal mahasiswa modern
- Sistem akademik resmi universitas
- Fokus tracking ijazah
- Minimalis
- Clean
- Professional
- Tidak terasa template admin generic
- Tidak terlalu corporate SaaS
