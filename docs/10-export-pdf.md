Export PDF System

## Priority

---

# Objective

Membangun sistem export PDF
berkualitas tinggi
untuk ijazah Universitas Royal.

PDF harus memiliki:

- kualitas print-ready
- layout presisi
- typography stabil
- tampilan konsisten
- ukuran optimal

---

# User Roles

## Admin / Biro Akademik

Dapat:

- export PDF ijazah
- batch export PDF
- download PDF

---

## Mahasiswa

Dapat:

- download PDF pribadi
- preview PDF pribadi

Jika status ijazah telah tersedia.

---

# Main Features

## Single PDF Export

Export satu ijazah menjadi PDF.

---

## Batch PDF Export

Export banyak ijazah sekaligus.

---

## PDF Download

Download hasil PDF.

---

## Print-Ready PDF

PDF siap dicetak tanpa perubahan layout.

---

## Secure PDF Access

PDF hanya dapat diakses user berwenang.

---

# Main Workflow

## Single Export Flow

1. Admin membuka preview ijazah
2. Admin klik Export PDF
3. Sistem generate PDF
4. PDF ditampilkan/download

---

# Batch Export Flow

1. Admin memilih banyak mahasiswa
2. Admin klik Batch Export
3. Sistem generate multiple PDF
4. Sistem download ZIP/PDF batch
