# Objective

Membangun design system
yang konsisten,
modern,
dan profesional
untuk seluruh sistem Royal Academic Print Suite.

Design system bertujuan untuk:

- menjaga konsistensi UI
- mempercepat development
- mempermudah maintenance
- meningkatkan user experience
- membantu AI agent menghasilkan UI konsisten

---

# Design Philosophy

## Main Design Direction

Sistem harus terasa seperti:

- modern university portal
- enterprise academic dashboard
- clean SaaS application
- professional administration system

---

# Design Principles

## UI Principles

- clean layout
- minimal clutter
- consistent spacing
- elegant typography
- clear hierarchy
- responsive interaction

---

# Forbidden Design Style

Hindari:

- neon cyberpunk
- gaming dashboard
- excessive gradients
- over animation
- colorful chaos
- outdated bootstrap feel
