# Objective

Membangun sistem pengelolaan template ijazah
yang fleksibel, presisi,
dan mudah digunakan oleh Admin/Biro Akademik.

Sistem harus memungkinkan admin
mengatur layout ijazah,
background template,
dan posisi teks
tanpa perlu mengubah kode secara manual.

---

# User Role

## Admin / Biro Akademik

Hanya admin yang dapat:

- upload template
- mengatur layout
- mengubah posisi teks
- mengatur typography
- mengaktifkan template

# Main Workflow

## Template Setup Flow

1. Admin membuka menu Template Ijazah
2. Admin upload template
3. Sistem memvalidasi file
4. Sistem menampilkan preview template
5. Admin mengatur posisi elemen
6. Admin menyimpan konfigurasi
7. Template dapat digunakan untuk preview dan print
