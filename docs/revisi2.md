# FINAL UI POLISHING — STUDENT PORTAL DASHBOARD

Tujuan:
Lakukan refinement terakhir agar dashboard mahasiswa terasa lebih profesional, akademik, clean, dan memiliki identitas produk sendiri.

Fokus hanya pada polishing visual dan UX kecil.
Jangan redesign ulang layout utama.

---

# 1. HAPUS SEARCH BAR TOPBAR

Hapus search bar:

" Cari fitur atau data... "

Karena dashboard mahasiswa tidak membutuhkan fitur pencarian besar seperti admin panel.

Ganti area tersebut dengan informasi akademik ringan seperti:

"Status Akademik: Aktif"

atau

"Semester Genap 2026/2027"

Gunakan style subtle minimal modern.

Topbar harus terasa seperti portal akademik, bukan dashboard inventory/admin template.

---

# 2. GANTI BRANDING "PRINT SUITE"

Pada sidebar branding kiri atas:

Ganti:
"PRINT SUITE"

menjadi:

"PORTAL IJAZAH"

atau

"DOKUMEN AKADEMIK"

Pertahankan:
- logo
- ukuran typography
- style branding

Tujuannya agar branding lebih relevan dengan konteks mahasiswa dan sistem akademik.

---

# 3. PERBAIKI JUDUL HALAMAN

Ganti title:

"Dashboard Portal Saya"

menjadi:

"Portal Akademik Saya"

atau cukup:

"Beranda"

Gunakan wording yang lebih modern dan natural.

---

# 4. TINGKATKAN READABILITY LABEL DATA AKADEMIK

Naikkan sedikit:
- opacity
- contrast
- font weight

pada label seperti:
- NOMOR INDUK MAHASISWA
- PROGRAM STUDI
- FAKULTAS
- TAHUN MASUK

Karena saat ini label terlalu pucat dan kurang readable.

Tetap gunakan style clean minimal.

---

# 5. PERBAIKI TIMELINE PROSES IJAZAH

Pertahankan struktur timeline saat ini.

Tingkatkan visual hierarchy dengan:
- connector line lebih jelas
- warna progress aktif lebih terlihat
- completed step hijau
- current step biru
- pending step abu soft

Tambahkan sedikit emphasis pada step aktif.

Jangan tambahkan animasi berlebihan.

---

# 6. PERBAIKI CARD IPK

Card IPK saat ini sudah lebih baik, namun masih memiliki ruang kosong berlebih.

Tambahkan informasi kecil tambahan seperti:

"Status Kelulusan: Terverifikasi"

atau

"Dokumen Akademik Aktif"

Gunakan typography kecil subtle.

Tetap fokus utama pada:
- angka IPK
- predikat kelulusan

Jangan membuat card menjadi ramai.

---

# 7. PERBAIKI FOOTER SIDEBAR

Ganti teks:

"KUNCI SIDEBAR"

menjadi:

"Sematkan Sidebar"

atau gunakan icon pin tanpa teks.

Karena wording saat ini terasa terlalu teknikal dan kurang natural untuk user umum.

---

# 8. KURANGI SEDIKIT WHITESPACE

Lakukan refinement spacing kecil:
- kurangi sedikit tinggi hero
- rapikan jarak antar card
- kecilkan padding vertical berlebih

Tetap pertahankan clean layout dan readability.

Dashboard harus terasa:
- padat secukupnya
- hidup
- profesional

bukan kosong seperti template demo.

---

# 9. PERTAHANKAN YANG SUDAH BAGUS

JANGAN mengubah:
- sidebar layout
- warna utama biru & navy
- struktur data akademik
- gradient hero
- timeline section
- responsive layout
- style active navigation

Karena visual identity dashboard saat ini sudah cukup kuat.

---

# TARGET AKHIR

Dashboard mahasiswa harus terasa seperti:

- Portal akademik resmi universitas modern
- Fokus tracking ijazah dan dokumen akademik
- Clean
- Minimal
- Professional
- Premium academic system

BUKAN:
- template admin bootstrap
- SaaS analytics dashboard
- UI kit marketplace
- dashboard CRUD generic
