# Objective

Membangun dashboard mahasiswa modern
yang memberikan akses cepat terhadap:

- status ijazah
- preview dokumen
- download PDF
- QR verification
- informasi akademik dasar

Dashboard mahasiswa harus terasa ringan,
modern, profesional,
dan mudah digunakan.

---

# User Role

## Mahasiswa

Dashboard hanya dapat diakses oleh mahasiswa
yang telah login.

---

# Main Features

## Personal Dashboard

Menampilkan informasi pribadi mahasiswa.

---

## Certificate Status

Menampilkan status proses ijazah mahasiswa.

---

## Certificate Preview

Mahasiswa dapat melihat preview ijazah.

---

## PDF Download

Mahasiswa dapat mengunduh PDF ijazah
jika status sudah tersedia.

---

## QR Verification

Mahasiswa dapat melakukan validasi QR ijazah.
