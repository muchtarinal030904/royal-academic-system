# Objective

Membangun dashboard admin modern
yang memberikan ringkasan sistem akademik,
aktivitas pencetakan ijazah,
dan informasi penting secara cepat dan efisien.

Dashboard harus terlihat profesional,
responsif, dan memiliki nuansa
portal akademik modern universitas.
