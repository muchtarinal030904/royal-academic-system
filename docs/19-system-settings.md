# Objective

Membangun sistem pengaturan aplikasi
yang terpusat,
fleksibel,
dan mudah dikelola oleh admin.

System Settings bertujuan untuk:

- mempermudah konfigurasi sistem
- mengurangi hardcoded configuration
- mendukung branding universitas
- meningkatkan maintainability project

---

# User Role

## Admin / Biro Akademik

Hanya admin yang dapat:

- mengubah pengaturan sistem
- mengubah branding
- mengatur konfigurasi aplikasi

# Main Workflow

## Settings Update Flow

1. Admin membuka halaman settings
2. Admin mengubah konfigurasi
3. Sistem memvalidasi input
4. Sistem menyimpan pengaturan
5. Perubahan diterapkan otomatis
