# Objective

Membangun sistem histori pencetakan
untuk melacak seluruh aktivitas cetak ijazah
secara detail, aman,
dan terorganisir.

Sistem histori bertujuan untuk:

- audit aktivitas pencetakan
- monitoring admin
- tracking dokumen
- mengurangi kesalahan pencetakan
- meningkatkan keamanan dokumen akademik

---

# User Role

## Admin / Biro Akademik

Dapat:

- melihat histori pencetakan
- mencari histori
- filter histori
- melihat detail aktivitas print

---

# Main Features

## Print History List

Menampilkan seluruh histori pencetakan.

---

## Print Detail

Melihat detail aktivitas print tertentu.

---

## Print Search

Mencari histori print.

---

## Print Filter

Filter histori berdasarkan kategori tertentu.

---

## Print Tracking

Melacak siapa dan kapan ijazah dicetak.

---

# Main Workflow

## Print Logging Flow

1. Admin melakukan print/export PDF
2. Sistem mencatat aktivitas
3. Data histori disimpan
4. Histori tampil pada dashboard histori
